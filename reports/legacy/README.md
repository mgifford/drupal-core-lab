# Legacy reports

Historical reports kept for reference. They are **not** maintained, are **not** part of the current issue-lab
workflow, and may reference scripts and paths that no longer exist. Current reports start at
[../README.md](../README.md) and [../issues/README.md](../issues/README.md).

| Folder | What it contains |
|---|---|
| `default-admin/` | The Default Admin theme accessibility report family, keyboard/pattern/plain-language reports, and the old report index. Moved from the root of `reports/` on 2026-11-28. |
| `design-scans/` | Raw design-observation scans from the October 2026 experiments (large JSON files; local evidence, not a published report). Moved from `reports/local-design/` on 2026-11-28. |

Do not add new reports here. Add an issue under `reports/issues/<nid>/`, or a cross-issue report under the
relevant current folder.
