# Resource reports

Generated by deterministic code from the local resource ledger. No AI model is called to produce them.

| File | What it is |
|---|---|
| [BASELINE.md](BASELINE.md) | Current baseline: provider-reported tokens, activity attribution, Unknown reasons, reconciliation, prompt metadata and opportunities. |
| [SUMMARY.md](SUMMARY.md) | The same current summary without the baseline label. |
| [summary.json](summary.json) | Machine-readable current summary; the public dashboard reads this through `cloud/resources.json`. |
| [ATTRIBUTION-AUDIT.md](ATTRIBUTION-AUDIT.md) | Unknown investigation: reason codes, coverage, reconciliation, remediation candidates and what is not fixable with this telemetry. |
| [METHODOLOGY-COMPARISON.md](METHODOLOGY-COMPARISON.md) | Archived session tool-call-share results compared with request-level accounting. Not an efficiency claim. |
| [HANDOFF-2026-11-23.md](HANDOFF-2026-11-23.md) | What changed, tests run, what was not verified and next steps. |
| [archive/2026-11-23/](archive/2026-11-23/) | The historical baseline, summary and JSON preserved unchanged before request-level re-accounting. |

Reproduce:

```bash
node scripts/resource.mjs audit
node scripts/resource.mjs report --write --baseline
node scripts/resource.mjs report --check
node scripts/build-cloud.mjs
node scripts/resource-benchmark.mjs
```
