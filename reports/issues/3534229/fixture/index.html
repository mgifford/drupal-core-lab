#3534229 — CKEditor 5 toolbar configuration, three implementations

This page frames the same Core toolbar-configuration markup with three implementations: A current core (background-image), B Kent's whole-element mask experiment from issue comment #7, and C the proposed dedicated mask in CanvasText. A simulated contributed plugin (contribExample, last in Available buttons) only sets a background-image, as the backward-compatibility control.

Serve this directory over HTTP and enable forced colours in the browser (Chromium: DevTools → Rendering → Emulate CSS media feature forced-colors: active, plus prefers-color-scheme: dark for the dark palette; the Lab browser has a forced-colours switch). Do not open it with file://: Chromium refuses to load mask-image resources from file:// (CORS), which would be mistaken for a broken fix.
