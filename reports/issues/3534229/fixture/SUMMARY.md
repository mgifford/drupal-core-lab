## Reading the result

- In forced-colors mode, background images whose value contains `url()` are **kept** (`background-image` is only forced to `none` for values without `url()`), so the black SVG icons stay black while `Canvas` turns black in the dark palette: every icon-only control loses its icon in forced-colors **dark**, and keeps it in forced-colors light.
- A non-empty `mask-image` computed value is not proof of visibility: the `mask set but no pixels` column lists items where the mask exists but no distinguishable pixel was rendered.
- The `contribExample` control must stay exactly as it is in A (visible in forced light, invisible in forced dark): an opt-in-only fix must not change it.
