## Issue-specific scenario (from the registered variant)

1. **recipe:** Start with a Standard install and Default Admin. Log in to both sites as a user who can view unpublished nodes and held comments. For the Core pass, set Default Admin as the default theme on both sites so it renders the lab pages.

2. **recipe:** Create three nodes with fixed aliases: /lab/published-article (published, one published comment), /lab/unpublished-article (unpublished, one published and one held comment), and /lab/unpublished-page (unpublished Basic page, author metadata hidden). 3. **mirror:** Open /lab/unpublished-article and /lab/unpublished-page in Default Admin on both sides.
   Observe: Compare Before with After. On After, each unpublished node and the held comment has one visible Unpublished label with screen-reader context, including the Basic page without author metadata. The published comment has no unpublished label.

4. **mirror:** For the contributed-theme passes, set Claro as the default theme on both sites and repeat both unpublished pages, then do the same for Olivero. For Starterkit, repeat with a theme generated from each side's Starterkit templates; existing generated themes do not update automatically.
   Observe: The same After labels are present regardless of the theme. Record which themes were actually checked; separate automated suites for every theme are not required.

5. **mirror:** Open /lab/published-article in each theme being checked, on both sides.
   Observe: The published node and its comment have no Unpublished label or screen-reader status.

6. **observe:** Repeat the checks in light mode, dark mode where supported, and forced colours. Compare the same theme and display preference on both sides.
   Observe: On After, the status remains identifiable from readable text and does not depend on background colour. A dark preference alone does not prove a native dark palette.
