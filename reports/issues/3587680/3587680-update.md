# Issue #3587680 Update: Empty heading tags on dialog and tabs pages

## Root Cause

The `filter-tips.html.twig` template expects `#tips` structured as:

```php
[
  'Format Label' => [
    'name' => 'Format Label',
    'list' => [
      ['tip' => ['#markup' => '...']],
    ],
  ],
]
```

The `DialogController::buildFilterTips()` and `TabController::buildTipsRenderArray()` were providing:

```php
[
  'Format Label' => [
    'filter_id' => [
      'tip' => ['#markup' => '...'],
      'id' => 'filter_id',
    ],
  ],
]
```

When the template iterates `{% for name, tip in tips %}`, `tip` is the filter-ID-keyed array without `name` or `list` keys. The `<h3>{{ tip.name }}</h3>` renders empty because `tip.name` is null.

## Fix

Restructure both controllers to group filter tips at the format level:

- `DialogController::buildFilterTips()` — build `$tips[$format->label()]` with `name` and `list` keys
- `TabController::buildTipsRenderArray()` — same restructuring, plus correct `#tips` render array format

## Files

- `modules/contrib/theming_tools/modules/dialog/src/Controller/DialogController.php`
- `modules/contrib/theming_tools/modules/tab/src/Controller/TabController.php`

## Verification

Before fix:
```
curl -s https://drupal-core.ddev.site/dialog | grep -c "<h3></h3>"
4
```

After fix:
```
curl -s https://drupal-core.ddev.site/dialog | grep -c "<h3></h3>"
0
curl -s https://drupal-core.ddev.site/dialog | grep "<h3>"
<h3>Basic HTML</h3>
<h3>No editor</h3>
<h3>Restricted HTML</h3>
<h3>Plain text</h3>
```

Both `/dialog` and `/tabs` pages now render proper h3 headings with format names. The axe-core `empty-heading` violation (affecting 7% of pages per Lighthouse audit) is resolved.
