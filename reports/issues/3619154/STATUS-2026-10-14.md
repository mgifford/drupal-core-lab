## What the MR does (from the summary)

Reworks the Default Admin node add/edit meta sidebar:
- Splits `migration/js/sidebar.js` into a `sidebar-toggle` SDC + `js/edit-sidebar.js`.
- Toggle and close controls are now `<button>` elements (were `<a role="button">`); toggle is operable with Space.
- Sets open/closed state before first paint (no flash); open/closed state and width persist across reload.
- Below 1024px: content under the overlay is `inert`, focus moves into the sidebar, Escape closes it and returns focus to the toggle.
- Opening the sidebar no longer collapses Navigation on content-height change.
- Positions the sidebar with CSS variables (no jump / top-bar overlap); resize works after AJAX, with touch, and in RTL; resize handle hidden below 976px.
