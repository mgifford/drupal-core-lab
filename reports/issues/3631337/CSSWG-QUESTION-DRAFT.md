# Draft only: error and warning presentation in forced colors

What approach does the CSS Working Group recommend for error and warning indicators when forced colors is active? CSS Color 4 defines no dedicated error or warning system colors. Drupal currently uses CanvasText for consistent grouping-error icons and borders, but selected tabs can use the same color.

Should authors continue using foreground system colors with distinct icons, text, and border shapes, or would dedicated error and warning system colors be appropriate? If new colors are considered, how should their foreground/background pairing, native contrast palettes, custom palettes, and fallback behavior work?

References: https://www.w3.org/TR/css-color-4/#css-system-colors and https://www.drupal.org/project/drupal/issues/3631337 . The local double-border experiment is evidence to discuss, not a standards proposal or accepted recommendation.
