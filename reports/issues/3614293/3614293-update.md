# Issue #3614293 Update: Automated Form Validation Accessibility Testing

## What Changed

Added test coverage for `aria-invalid="true"` across 13 form element types. The existing Drupal core had a single test (`FormTest::testRequiredTextfieldNoTitle`) that only checked textfields. This patch expands coverage to textarea, select, checkboxes, radios, email, password, tel, url, number, color, and date.

Also added guidepup virtual screen reader tests to verify that form validation errors produce correct accessibility tree output.

## Files

- `core/modules/system/tests/modules/form_test/src/Form/FormTestAriaInvalidForm.php` — Test form with 13 element types
- `core/modules/system/tests/src/Functional/Form/FormAriaInvalidTest.php` — 12 Functional tests
- `core/modules/system/tests/modules/form_test/form_test.routing.yml` — Route for test form
- `tests/playwright/tests/a11y-aria-invalid-sr.spec.ts` — 3 guidepup virtual SR tests

## Coverage Summary

| Element | Required | Validation | aria-invalid set | aria-invalid cleared |
|---------|----------|------------|------------------|---------------------|
| textfield | yes | #required | yes | yes |
| textarea | yes | #required | yes | n/a |
| select | yes | #required | yes | n/a |
| checkboxes | yes | custom validator | yes | n/a |
| radios | yes | #required | yes | n/a |
| email | yes | #required | yes | n/a |
| password | yes | #required | yes | n/a |
| tel | yes | #required | yes | n/a |
| url | no | #maxlength | yes | n/a |
| number | no | #min/#max | yes | n/a |
| color | no | optional | no (correct) | n/a |
| date | no | optional | no (correct) | n/a |

## What This Does Not Cover

- CKEditor5 (covered by existing `CKEditor5AllowedTagsTest` and `StyleTest`)
- Date/datetime with invalid format (requires JavaScript for HTML5 validation)
- `aria-errormessage` association (not yet in Drupal core)
- Cross-theme testing (Claro, Olivero)


## Notes

The `aria-invalid` attribute is set centrally in `RenderElementBase::setAttributes()` at `core/lib/Drupal/Core/Render/Element/RenderElementBase.php:151`. All form elements that extend `RenderElementBase` inherit this behavior when `#errors` is set and `#validated` is truthy.
