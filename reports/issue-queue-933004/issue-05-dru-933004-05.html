Summary

Icon-only and image buttons in admin UI lack accessible names; give them #title or aria-label.

Description

Many admin controls are rendered as icon buttons (e.g., remove, drag, settings) without text or title.

Steps to reproduce

  1. Open a View in the Views UI
  2. Tab through icon buttons
  3. Run axe-core

Expected result

Each button exposes an accessible name.

Actual result

Icon/image buttons are unnamed per the baseline.

Testing environment

  • Drupal 11.x
  • FunctionalJavascript + axe-core

Impact

Admins cannot operate icon-only UI with keyboard + AT.

Suggested fix

Add #title or aria-label to icon/image buttons; prefer visually-hidden text where space allows.

Scope

  • submit
  • button
  • image_button elements
  • admin toolbars

Out of scope

  • Olivero/Claro theme visual changes

Open questions

  • Prefer aria-label vs visually-hidden span for icon buttons?
