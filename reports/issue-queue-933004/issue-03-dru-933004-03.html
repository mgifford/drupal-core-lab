Summary

TableSelect renders a select-all checkbox plus per-row checkboxes but labels are not distinct/scoped; fix the per-row accessible names.

Description

The master checkbox has a #title; per-row checkboxes inherit it, so each row's control is indistinguishable to AT. Rows also need an association between the checkbox and the row's primary text.

Steps to reproduce

  1. Visit /admin/content
  2. Inspect the bulk-select checkboxes
  3. Run axe-core

Expected result

Each row checkbox has a unique, descriptive accessible name (e.g., 'Select <entity label>').

Actual result

Row checkboxes share the master label; axe flags duplicate/ambiguous names.

Testing environment

  • Drupal 11.x
  • FunctionalJavascript + axe-core

Impact

Admins cannot reliably select specific rows with a screen reader.

Suggested fix

Generate per-row aria-label/title from the row's primary field; keep the master checkbox label generic.

Scope

  • TableSelect preRender
  • Theme override if needed

Out of scope

  • Visual redesign of tables

Open questions

  • Use aria-label or a visually-hidden label span?
