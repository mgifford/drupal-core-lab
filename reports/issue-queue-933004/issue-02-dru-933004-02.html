Summary

Content Translation and Language modules build shared form elements (metadata, negotiation, detection) without accessible names; give them #title.

Description

These modules inject controls into nearly every translatable entity form. They are a high-leverage surface: fixing them improves titles across many edit screens at once.

Steps to reproduce

  1. Enable content_translation + language.
  2. Edit a translatable node, open the Translation tab.
  3. Run axe-core / inspect with a screen reader.

Expected result

Every control has a visible, programmatically associated label (#title).

Actual result

Several controls lack #title and are reported as unlabeled by the Part 1 baseline.

Testing environment

  • Drupal 11.x
  • FunctionalJavascript + axe-core
  • Screen reader (NVDA/VoiceOver) for confirmation

Impact

Translators and multilingual editors using assistive tech cannot identify controls.

Suggested fix

Add #title to each unlabeled element in ContentTranslationMetadataFormBase and language negotiation/detection forms; update the baseline.

Scope

  • content_translation forms
  • language negotiation/detection forms

Out of scope

  • Entity-level title copywriting (handled in later parts)

Open questions
