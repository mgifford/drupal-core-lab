Summary

Define which form/render elements require an accessible name, document it, and surface it via ElementInfo metadata so the detector and reviewers share one source of truth.

Description

Without a documented rule, titles are added inconsistently. Codify: labelable controls (textfield, checkbox, select, radio, button, submit, file, tableselect) require #title unless explicitly decorative/aria-hidden.

Steps to reproduce

  1. Read core/lib/Drupal/Core/Render/Element/FormElement.php
  2. Propose a require-title element list
  3. Update Form API topic

Expected result

A documented, machine-readable list of elements that require #title.

Actual result

No canonical rule exists; MR !7659 grew ad hoc.

Testing environment

  • Drupal 11.x
  • Docs + ElementInfoManager

Impact

Future code stays accessible by construction; reviewers have a reference.

Suggested fix

Add require_title metadata to ElementInfoManager; document in themeable/Form API topic; align Part 1 detector with it.
