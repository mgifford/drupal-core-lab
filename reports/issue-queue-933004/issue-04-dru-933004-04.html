FrequencyEvery field widget instance across all entity forms.

Summary

Field widgets build sub-elements (delta markers, add-more buttons, file upload controls) without #title; add them.

Description

Text/number/options/file widgets produce controls that lack accessible names, especially multi-value 'add another' and file inputs.

Steps to reproduce

  1. Create a content type with multi-value fields
  2. Edit a node
  3. Run axe-core

Expected result

All widget controls are labeled.

Actual result

Add-more buttons and file controls are unlabeled per the baseline.

Testing environment

  • Drupal 11.x
  • FunctionalJavascript + axe-core

Impact

Content authors using AT cannot operate multi-value or file widgets.

Suggested fix

Provide #title / aria-label for add-more buttons and file inputs in each widget.

Scope

  • text
  • number
  • options
  • file widgets

Out of scope

  • Custom/contrib widgets (out of core scope)

Open questions

  • Standard label pattern for 'Add another item'?
