Once the title requirement is documented (Part 7) and the baseline is stable, emit an E_USER_DEPRECATED when a labelable element is rendered without #title.

Description

Final enforcement step: turn the static detector into a runtime deprecation so contrib/custom code is nudged to comply, with an opt-out for intentional decorative controls.

  2. Render it
