    Mirror repeats real clicks, typed text, checkboxes and selects in the other frame to save setup time. It does not mirror the keyboard (Tab, Enter, focus), because script-generated key events do not behave like real ones. Do the final keyboard check in each frame yourself.

    Frames are separate sites on before.localhost and after.localhost, so logins do not interfere. This compares behaviour in a browser. It is not a substitute for testing with a keyboard and a screen reader.
