This Drupal 7 guide is archived and no longer maintained. Drupal 7 reached end of life on January 5, 2025. Some pages in this guide describe unsupported Drupal APIs, obsolete web techniques, and outdated accessibility tools or requirements.

Current accessibility guidance is being consolidated under Accessibility. Use that guide when developing, reviewing, or maintaining themes for supported Drupal versions.

If you maintain a Drupal 7 site, do not treat these archived pages as current best practice. Verify implementations against current standards, browser behavior, and assistive technologies. See Drupal 7 End of Life for migration resources and extended-support options.
