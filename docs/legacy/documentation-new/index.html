About This Review

This is a working editorial index, not the current Drupal.org accessibility guide. It connects each recommendation to its Drupal.org source, local source snapshot when one was retained, proposed replacement, and change record.

A proposed draft has not been accepted until it is reviewed and published on Drupal.org. The priority numbers describe editorial review order. They are not accessibility severity, conformance status, or implementation priority.

  • Priority 1: Foundation and development standards.
  • Priority 2: Implementation guides.
  • Priority 3: Review processes and supporting resources.

Legacy Drupal 7 documentation

Drupal 7 reached end of life on January 5, 2025. The Drupal 7 pages linked from this index may contain unsupported PHPTemplate code, obsolete Drupal APIs, old CSS classes, outdated Web Content Accessibility Guidelines references, and abandoned tools or modules.

The fifteen child pages in the old Creating accessible themes guide are not being recreated as fifteen current pages. Their useful material is being consolidated into six maintainable guides for supported Drupal releases:

  • Creating Accessible Themes
  • Building Accessible Forms
  • Page Structure and Navigation
  • Accessible JavaScript and Interactive Components
  • Accessible Images and Media
  • Color, Contrast, and Typography

The existing current pages for hiding content and contributed modules are revised in place. The Drupal 7 tools and resources pages receive archival pointers to maintained evaluation and resource guidance. Legacy URLs remain here for provenance and redirect planning, not as implementation recommendations.
